## 🔍 Question Tracking in Action

### **How It Works:**
1. Student takes exam
2. System tracks when they switch tabs
3. System records which question they approximately on
4. Export shows: "Switch at Q20" = Mid-exam distraction
5. Admin can instantly see: When + Where the issue happened

### **Real-World Example:**
```
Filter by: Approx Q During Switch = Q1-Q10
Result: Early switchers (minor issue)

Filter by: Approx Q During Switch = Q40-Q50 AND Tab Switches > 5
Result: Late-exam cheating attempts (major issue)
```

## 📝 How to Use Tab Switch Sheet

### **Quick Analysis:**

1. **"Which question had the switch?"**
   - Look at "Approx Q During Switch" column
   - See values like: Q1, Q5, Q20, Q35, etc.

2. **"Who skipped questions?"**
   - Look at "Q Skipped" column
   - Filter for > 5

3. **"Suspicious pattern?"**
   - Filter: High switches + Late Q + High score
   - = Possible external help

4. **"Who was rushing?"**
   - Look at "Avg Sec/Q" column
   - Filter for < 20 seconds
