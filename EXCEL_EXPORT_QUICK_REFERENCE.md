## 📈 Chart Creation Example

**Using Chart Data Sheet (Built-in):**
1. Open Excel file
2. Go to "Chart Data" sheet
3. Select all three columns (Name, Attempted, Accuracy %)
4. Insert → Scatter Chart or Bubble Chart
5. Title: "Student Performance Scatter"
6. Analyze clusters and outliers

**Interpretation:**
- 🔴 Bottom-right: Few attempts, Low accuracy = Needs help
- 🟢 Top-right: Many attempts, High accuracy = Strong student
- 🟡 Top-left: Few attempts, High accuracy = Quick learner
- ⚫ Bottom-left: Few attempts, Low accuracy = At risk

## ⚙️ Technical Details

**Data Filtering:**
- Only includes submitted attempts
- Filters: "Completed exam" or "Limit exceed" status
- Applied across all sheets consistently

**Color Scheme:**
- Header: Dark Green #008037 (White text, bold)
- Alternating: Light Green #FFF1F8E9
- Correct: Green #FF4CAF50
- Wrong: Red #FFF44336
- Unattempted: Yellow #FFFFFF00
- Tab Exceeded: Light Red #FFFFE0E0

**Calculations Used:**
```
Accuracy % = (Correct / (Correct + Incorrect)) × 100
Avg Time = Total Time / Number of Attempts
Pass % = (Pass Count / Total Completed) × 100
Completion % = (Completed / Total Candidates) × 100
```

## 🔧 Troubleshooting

### **Sheets Look Distorted?**
- Auto-fit column widths in Excel
- Check row heights aren't minimized
- Zoom to 100% for proper view

### **Colors Not Showing?**
- Verify Excel is not in "Compatibility Mode"
- Check Excel color settings
- Ensure file is .xlsx (not .xls)

### **Missing Data?**
- Only submitted attempts are included
- Incomplete attempts are filtered out
- Check status: "Completed exam" or "Limit exceed"

### **Numbers Look Formatted Strangely?**
- Center alignment applied for readability
- Check Excel regional settings match system locale
- % symbols intentional for percentages
