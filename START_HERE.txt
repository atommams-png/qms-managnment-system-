🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: MySQL not running
  → Start MySQL service in Windows Services or use: mysql.server start

Issue: Port 5000 already in use
  → Change PORT in backend/.env or kill process on port 5000

Issue: Database init fails
  → Verify MySQL is running and credentials are correct

Issue: Cannot access frontend
  → Check Vite is running and no port conflicts

Issue: API not responding
  → Ensure backend server is running on port 5000
